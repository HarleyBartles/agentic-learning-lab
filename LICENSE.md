## Mixed files and exceptions

A Markdown or other educational file does not become MIT-licensed merely because it contains a code snippet. Code examples embedded in curriculum material remain part of the CC BY 4.0 educational work unless they are explicitly marked otherwise.

A standalone software file may state its licence with an SPDX header such as `SPDX-License-Identifier: MIT`; that file-level declaration controls for that file.

Third-party material, if any, remains subject to its own licence or rights notice. Nothing in this repository-level policy grants rights that the repository owner does not have authority to grant.

If a file carries an explicit licence or copyright notice that conflicts with this repository-level default, the file-level notice controls.
