# Module 1 — Stage 1

## Start clean

Before starting, delete `labs/01-cloud-vs-local/output/mission-brief.md` if it exists.

## Task

Complete the mission in:

`labs/01-cloud-vs-local/`

Use ordinary cloud ChatGPT.

ChatGPT cannot see the project folder. Make sure it has all of the information it needs, then use it however you want to produce the required mission brief and get the finished file into the local `output/` folder.

There is no required upload, download, or copy/paste technique.

## Stage complete

Stop when the mission brief exists locally and satisfies the lab win condition.

Do not delete it yet.

## Reflect

Talk through:

- What information did you have to move into ChatGPT?
- How did you decide ChatGPT had everything it needed?
- What did you have to do to get the finished artifact back into the project?
- Which parts of the work were about the mission, and which parts were just moving information between environments?
