# Lab 2 — Exercise 2: Can you see it?

Use the same question in each run:

> According to the venue plan, which labelled table is closest to the accessible entrance?

## Run A

Ask cloud ChatGPT to answer using only its repository access.

Do not upload the image directly.

## Run B

Ask the prepared on-disk agent the same question from the local Lab 2 project.

## Run C

Give the venue-plan image directly to cloud ChatGPT and ask the same question again.

## Reflect

Talk through:

- Was the image part of the repository in every run?
- Did every access route expose the image in a form the agent could actually inspect?
- Did the cloud model become more capable in Run C, or did the available project surface change?

The important observation is that an agent can have access to a project while still lacking the particular representation needed for a task.
