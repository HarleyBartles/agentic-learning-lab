# 05 — What would prove it?

Different claims need different evidence.

For each statement below, decide what you would want to inspect before accepting it:

```text
"The old wording is gone from current visitor output."

"The PDF is ready to send."

"The application works."

"The change is merged on GitHub."

"This research conclusion is grounded."
```

Possible evidence might include:

```text
current visitor wording
→ scoped search + diff + read

PDF ready
→ render + inspect the rendered artifact

application works
→ suitable tests + runtime behaviour

merged on GitHub
→ remote GitHub merge/main evidence

research grounded
→ citations + provenance + contradiction checks
```

The point is not to memorise one verification tool.

Earn:

> **Verification is claim-dependent and artifact-dependent.**

Carry two questions into any real agent task:

Before execution:

> **What source defines correct here?**

After execution:

> **What evidence would make me willing to accept this work?**

That is the handoff into Lab 10.
