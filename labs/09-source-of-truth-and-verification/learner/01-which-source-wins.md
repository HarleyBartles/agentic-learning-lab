# 01 — Which source wins?

The Repair Café project disagrees with itself.

Some files use one public programme name. Others use another.

Do not change anything yet.

Ask the worker:

> What is the currently approved public programme name? Show me the project evidence for that answer, identify which source makes it authoritative, and explain why the other conflicting mentions do not win. Do not change anything yet.

You are looking for more than the right value.

Ask:

- Which file contains the current approved value?
- Which project rule says that source wins?
- Are the other mentions wrong, stale, historical, or simply non-authoritative for this question?
- Did the worker infer authority from a filename, recency, or tone, or can it actually show the project rule?

Earn:

> **Access is not authority.**

And:

> **Authority should be explicit rather than inferred from whichever source looks newest or sounds most official.**

When you can explain which source defines correct and why, move on.
