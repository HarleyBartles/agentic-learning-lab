# Lab 9 working fixture

This directory contains the bounded Repair Café project used by Lab 9.

Point the local worker at `repair-cafe/`, not at the teaching material above it.

The fixture deliberately contains:

- an explicit authority map;
- one authoritative current visitor brief;
- honest historical evidence and archived copy containing an older programme name;
- stale current visitor-facing output containing that older name.

Do not repair the stale output before the learner reaches Exercise 2.

The contradiction is intentional experimental apparatus.
