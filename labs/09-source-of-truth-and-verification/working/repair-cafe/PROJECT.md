# Repair Café project authority map

This project deliberately contains current state, historical evidence, archived copy, and derived visitor-facing output.

For the **currently approved public programme name**, the authoritative source is:

`requirements/current-visitor-brief.md`

Other files may mention older or derived values. Those files do not override the current visitor brief merely because they are newer-looking, public-facing, or contain the same topic.

## Surface roles

```text
requirements/
current approved requirements and decisions for visitor-facing work

evidence/
preserved records of what was discussed or decided at the time

archive/
historical published copy retained for reference

output/
current visitor-facing material derived from current requirements
```

Preserve historical records honestly. Update current output when the current requirement changes.
