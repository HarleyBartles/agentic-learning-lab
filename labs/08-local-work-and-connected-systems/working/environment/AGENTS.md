# Environment-specific instructions

- This directory is a navigation experiment.
- Treat `INDEX.md` as the project's declared navigation mesh when the learner explicitly asks you to use the mesh.
- When constrained to the mesh, follow only paths named by reachable index files and do not compensate with recursive listing, globbing, grep, search, or other broad discovery.
- If the mesh does not establish an answer, say what you inspected and that the answer remains unestablished through that route.
- If the learner later names a path directly, you may inspect that path normally.
- Do not modify the fixture during the experiment unless the learner explicitly asks.
