# Field exercise overview

The field exercise is a small coordination drill used to test whether a worker can orient itself from the project's declared navigation structure.

Normal operating assumptions:

- use the project indexes when asked to navigate through the declared mesh;
- distinguish what the mesh establishes from what the filesystem might contain more broadly;
- if an escalation detail is needed, consult the documented reference material reachable through the mesh;
- do not invent missing operational facts.

The exact escalation keyword is not stated in this overview.
