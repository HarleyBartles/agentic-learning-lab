# 02 — Follow the mesh

Open `working/environment/INDEX.md`.

This file is a project navigation convention. It is not the same kind of mechanism as `AGENTS.md`.

Ask the local agent:

> **Using only the INDEX.md navigation mesh, tell me what this environment contains and where the documented operating material lives. Do not perform a broad filesystem search.**

Watch how it moves through the index files.

Then compare the two mechanisms:

```text
AGENTS.md
what operating guidance applies here?

INDEX.md
where should I look next?
```

Ask yourself:

- Why might a large project prefer deliberate navigation over scanning everything every time?
- What does the index make easy to discover?
- What assumptions are we making when we trust the index as a map?

Do not inspect unrelated folders yet.

The next card will test what the map does **not** tell us.
