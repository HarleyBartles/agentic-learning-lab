# Lab 1 — Exercise 2: Missing context

## Start clean

Before starting, delete `mission/output/mission-brief.md` if it exists.

Start a **fresh ChatGPT conversation**.

Conversation memory should already be disabled for this exercise.

## Task

Repeat the same mission in `mission/`.

This time, deliberately do **not** give ChatGPT:

`mission/source/late-update.md`

Give it the other source material and ask it to produce the mission brief.

Do not tell ChatGPT that a file has been withheld.

## Exercise complete

Stop when ChatGPT has produced its best mission brief from the information it was given and you have inspected the result.

The expected result is plausible but wrong about the current access route and timing because the superseding update was invisible.

Do not delete the result yet.

## Reflect

Talk through:

- Did ChatGPT misunderstand the information it received?
- What critical fact was missing from its view of the project?
- Could ChatGPT know that another local file existed?
- Why did Exercise 1 succeed while this exercise failed?

The key observation is:

> Missing context is invisible context.
