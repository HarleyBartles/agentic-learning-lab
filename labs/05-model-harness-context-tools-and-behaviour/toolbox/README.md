# Lab 5 toolbox

This directory contains course-provided material that starts **outside** the worker's project boundary.

The learner may inspect and copy selected material into `../project/` during the exercises.

That movement is intentional teaching material: something can exist on the machine without being part of the worker's current project context or toolset.

Do not root the Lab 5 worker at the lab directory. Keep it rooted at `project/` so the boundary remains real.
