# Exercise 1 — Same job, different behaviour

You are going to give what appears to be the same worker the same job twice.

The facilitator will open the first prepared workspace.

Use exactly:

> Read `task.md` and do the task.

Read the result, but do not try to improve it yet.

The facilitator will then open the second prepared workspace in a fresh session.

Use exactly the same request:

> Read `task.md` and do the task.

Compare the two outputs.

Ask yourself:

- What stayed the same?
- What obviously changed?
- Did we intentionally change the job?
- Did we intentionally change the model?
- Did we intentionally change the harness?

Only after you have compared the outputs, inspect the `AGENTS.md` file in each workspace.

What explanation now fits the evidence best?

Keep this line:

> **Same model does not mean same behaviour.**

The thing you experience as `the AI` includes the instructions and configuration around the model.
