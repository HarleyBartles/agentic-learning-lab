# Exercise 2 — What context does it have?

This time the task and standing instructions stay the same.

The facilitator will give you a workspace containing a layout question.

Ask:

> Read `task.md` and answer it from the project evidence you can actually inspect.

Do not reward confident guessing. If the project does not contain the facts needed to decide, saying what is missing is a good result.

Then repeat the exact same request in the second prepared workspace.

Compare the answers and inspect what files were available in each workspace.

Questions to answer:

- Which layer changed?
- Was the first agent less intelligent, or less informed?
- If the first answer was weak, would changing model have been the first sensible fix?
- What should an agent do when required evidence is absent?

Keep this line:

> **Missing evidence is not evidence of a weaker model.**
