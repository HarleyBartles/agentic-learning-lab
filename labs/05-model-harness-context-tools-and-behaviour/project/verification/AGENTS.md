# Standing instructions

- Treat `constraints.md` and `candidate.csv` as read-only source material.
- Do not modify the schedule unless explicitly asked.
- If asked for an initial or manual assessment, inspect the files yourself and do not run `validate_schedule.py`; label the conclusion provisional.
- If explicitly asked to verify, run `python validate_schedule.py` and report the checker result as evidence.
- Distinguish what you inferred manually from what the checker proved.
