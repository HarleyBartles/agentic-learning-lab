# Lab 7 working surface

This folder is the agent-facing workspace for the live Lab 7 comparisons.

The facilitator should point the working agent here rather than at the whole lab where practical.

Create phase artifacts as the session runs, for example:

```text
working/
    phase-1/
        baseline.md
        provision.md
        provisioned-result.md
    phase-2/
        baseline.md
        provisioned-result.md
    phase-3/
        baseline.md
        provision.md
        provisioned-result.md
```

The exact filenames are not important. The important thing is to preserve enough of the baseline and provisioned outputs to compare them honestly.

Do not pre-populate this folder with the answer to the exercises.

The facilitator may clear generated phase artifacts before another learner runs the lab.
