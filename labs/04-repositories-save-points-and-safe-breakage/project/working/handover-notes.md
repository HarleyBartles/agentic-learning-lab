# Working handover notes — Northstar

These notes are for the crew taking over setup tasks during the day.

## Current expectations

- load-in starts at 08:00 via the Mill Lane loading bay;
- all crew ultimately report to Stage Door and sign in there;
- full crew call is 09:00;
- production-management briefing is 09:10 in the Green Room;
- keep cases out of the Stage Door corridor and crossover.

## Handover priorities

1. confirm departments have signed in;
2. confirm the loading bay is clear once unloading is complete;
3. flag access problems to production management;
4. make sure later arrivals know to report to Stage Door rather than waiting at the loading bay.

## Notes for improvement

This file overlaps with several production documents because it is intended to be useful as a quick handover sheet. The current structure has grown incrementally and is not necessarily the clearest possible presentation.
