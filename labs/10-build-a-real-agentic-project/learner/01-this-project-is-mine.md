# 1 — This project is mine

This is the first project in the course that exists because **you** chose to create it.

Pick something small enough to finish a useful first version today.

The default is a small GitHub Pages site: personal page, mini-portfolio, interests page, fictional page, or another simple public-facing site.

If you already have another small project you genuinely want, use that instead.

Before an agent builds anything, make three decisions:

1. **What are we making?**
2. **Who should be able to see it?**
3. **What reuse rights, if any, do you want to give other people?**

Keep these separate:

```text
visibility
who can see it

ownership
whose work it is

licence
what permission other people have to reuse it
```

A public repository is not automatically public-domain work.

You can keep normal default rights and add no broad reuse licence yet. Or you can deliberately choose a licence that grants reuse rights you actually want to grant.

An agent can explain options and prepare files. The decision is yours.

Create a new repository for this project. It should be separate from your Agentic Learning Lab fork.

Do not publish personal material just because the project exists. Publication comes later as a separate decision.

When the repository exists and you know what you are making, move to the next card.
