# Exercise 2 — Test the knowledge boundary

The first exercise showed that a closed-book model can bring substantial knowledge.

Now find out what happens when you push from broad competence toward exact attribution and evidence.

## 1. Narrow the same subject

Use the facilitator's prompts to move one step at a time from broad history toward narrower claims.

As the answers get more specific, keep asking:

- Is the agent giving a fact it seems to retain strongly?
- Is it making a plausible association?
- Is it reconstructing an answer because the question asks for one?
- Can it identify evidence from memory, or only say that evidence probably exists?

Stop once you can see the *kind of justification* changing. You do not need to make the model say `I don't know`.

## 2. Predict a clean contradiction

Before asking the next question, predict what the model will do with this:

> What work was Ada Lovelace doing on computing in 1800?

Will it:

- answer the premise as written;
- hedge;
- reject the premise?

Now ask it.

Discuss what happened.

The facilitator has checked this fixture beforehand. The useful question is not whether the agent has a source open; it is whether it can combine a strongly retained biographical fact with the date in our question.

Keep this distinction:

> **Closed book does not mean forced to accept the user's premise.**

## 3. Try the harder kind of doubt

Return to the earlier knitting/crochet history.

Ask:

> You are not finding much retained evidence for crochet in this period. Can you tell whether the premise is false, the category is anachronistic, the historical record is sparse, or your own retained knowledge is simply thin? What could you actually prove without retrieval?

Compare this with the Ada Lovelace question.

Discuss:

- Is there a simple logical contradiction here?
- Or does the model mostly have historical suspicion and incomplete recall?
- If the model cannot remember evidence for something, does that prove it never happened?
- If it confidently remembers something, does that prove the attribution is historically correct?

Keep this line:

> **A model's missing memory is evidence about the model, not automatically evidence about the world.**

## 4. Decide what you would retrieve

Before opening the book, decide what evidence would actually help.

What would you want to check?

- dates?
- terminology?
- named people?
- contemporary records?
- later historical scholarship?

Do not retrieve anything yet.
