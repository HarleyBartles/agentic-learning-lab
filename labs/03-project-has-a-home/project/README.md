# Riverside Repair Café pilot

This project is preparing a small pilot Repair Café at Riverside Community Hall.

The pilot is intended to help local people bring in small broken household items and work with volunteers to diagnose or repair them where practical.

## Current shape

The project already has:

- a confirmed venue and time window;
- four volunteers;
- a free-entry model;
- a one-item-per-visitor limit for the pilot;
- source notes from the venue, volunteers, and prospective attendees;
- a draft pilot plan;
- one unresolved operational decision about how arrivals should work.

Use the source material as evidence. Keep source files unchanged unless the task explicitly requires otherwise.

Working plans and project decisions may be updated as the project develops.
