# Venue notes

Riverside Community Hall is available on Saturday from 09:00 to 13:30.

The public session should run from 09:30 to 12:30 so volunteers have time to set up and clear down.

The main hall has six large tables, mains power around the perimeter, a small kitchen, accessible toilets, and step-free access through the side entrance.

The venue manager is happy for basic hand tools, soldering irons, multimeters, sewing equipment, and small electrical items to be used if volunteers supervise their own work areas.

The hall does not want petrol-powered equipment, large appliances, or anything that creates significant fumes, dust, or fire risk.

The entrance lobby can hold a short queue but should not become crowded.
