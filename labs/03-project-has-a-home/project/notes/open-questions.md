# Open questions

## Arrival and booking model

The pilot has not yet decided how visitors should arrive.

Options under discussion include:

- fully drop-in;
- pre-booked time slots;
- a hybrid model combining drop-in attendance with a small number of reserved slots.

The current project evidence supports different tradeoffs, so this remains a real decision rather than a fact waiting to be discovered.

## Later questions

These do not need resolving yet:

- whether future sessions should expand beyond one item per visitor;
- whether specialist repair categories need separate sessions;
- whether the pilot should collect donations after the first event.
