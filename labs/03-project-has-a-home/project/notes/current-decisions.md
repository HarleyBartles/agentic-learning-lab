# Current decisions

The following decisions are currently agreed for the pilot:

- Venue: Riverside Community Hall.
- Public session: Saturday, 09:30-12:30.
- Entry: free.
- Visitor limit: one broken item per visitor for the pilot.
- Scope: small household items and repairs that can be handled safely within the venue constraints.
- Repair style: volunteers work with visitors where practical rather than operating as a drop-off repair service.

The arrival and booking model has not yet been decided.
