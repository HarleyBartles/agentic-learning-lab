# Example projects

These small projects exist to demonstrate agentic work without making software development the centre of the learning.

Recommended examples:

- `writing-project/` — source material, working notes, and a generated report.
- `research-project/` — evidence gathering, notes, synthesis, and output.
- `technical-drawing/` — specification, deterministic drawing tooling, rendered output, and verification.

The projects should begin simple. Add instructions, tools, skills, and connectors only when the learner has encountered the problem they solve.
