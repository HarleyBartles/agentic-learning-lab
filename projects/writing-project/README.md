# Writing project

A small non-code project for comparing cloud-chat workflows with an agent working directly in a project directory.

Suggested structure as the exercise develops:

```text
writing-project/
    README.md
    source/
    working/
    output/
```

Start with a few source documents and a brief. First complete the task through ordinary cloud chat, then repeat it with an on-disk agent that can read the project directly and write the result into `output/`.

Do not add `AGENTS.md` immediately. Let repeated instructions become visible before capturing them as persistent project guidance.
